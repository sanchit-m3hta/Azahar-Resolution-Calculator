## How to use
- Enter the Horizontal resolution for the top screen; all other values are calculated automatically.
- Use the stretch percentage (%) to fill the screen as desired.
- Example: 5% stretch on the top screen, 25% on the bottom (this is what I have done)

## Calculations
This program calculates the following values for Azahar (3DS emulator) on the Anbernic RG476H:

### Top Screen
- X-Position
- Y-Position
- Width
- Height

### Bottom Screen
- X-Position
- Y-Position
- Width
- Height
